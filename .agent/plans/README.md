# ExecPlan Workspace

Store active execution plans in this directory using:

    YYYY-MM-DD-<short-slug>.md

Every plan must follow `../PLANS.md`. ExecPlan files belong under `.agent/`; do not place them in `docs/`.

When work is complete, either delete the plan if it has no continuing value or move it to `archive/` if it is useful implementation history. Extract durable workflow, database, operating, or business guidance into the canonical document under `docs/`.
